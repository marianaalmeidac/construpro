
# ConstruPro

**Portal B2B de compras para construção civil.**

## Tecnologias

- React
- TypeScript
- Vite

## Executar o projeto localmente

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

O Vite mostrará no terminal o endereço local para abrir a aplicação no navegador.

## Estrutura do projeto

- `src/components/` — componentes reutilizáveis, incluindo o menu lateral.
- `src/layouts/` — estrutura compartilhada das páginas.
- `src/pages/` — páginas do sistema.
- `src/assets/` — recursos visuais.
